# Process Overview

The brief asks for a multi-user, real-time website that is good, and leaves "good" to me. This account follows what I chose, what the agent proposed, and which fix landed in `CLAUDE.md` or a check rather than another retry. The [decision records](docs/adr/README.md) hold the detail.

## 1 Choosing a Game Worth Building

For crits 8 and 9 the app was Fridge Poetry, shared word magnets. After crit 9 I judged it unplayable, and scored rounds ([`4c5f328`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/4c5f328)) did not change that. I needed an idea that gets better the more people play it at once, so I had the agent survey classmates' projects for what was crowded: co-op, racing and cards. I proposed a shared FX market where players compete by leverage, parodying *FX Fighter Kurumi-chan*, with hidden-date crisis replays. I played the prototype, then replaced the fridge ([`66449d4`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/66449d4), [ADR 0009](docs/adr/0009-a-parody-fx-trading-floor.md)). I kept plain Node with a JSON file over Astro or SQLite, because a build step and a schema bought nothing for one small state; the cost is that every rule a database would enforce is mine to write ([ADR 0001](docs/adr/0001-plain-node-and-a-json-file.md)).

## 2 A Harness That Says No

The danger is a page that decides money. I had `CLAUDE.md` cut to rules alone ([`4269d0a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/4269d0a)): play money, no official art, satire of habits, never of people. Tests came before the broker in `src/fx.ts` ([`8c98e74`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/8c98e74)). The rule that a page sends only what the player chose, never a price ([ADR 0010](docs/adr/0010-who-may-see-and-change-what.md)), then shaped features I had not foreseen: when I asked for a pending order at a typed price, the agent made the level a trigger the server fills at its own price, and a test holds it ([`30c59a4`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/30c59a4)).

## 3 Real Data, Chosen Deliberately

I found thirty simulated days too long for a market that breaks in one. Random ticks between daily closes invented everything finer, so I chose HistData's free minute bars, credited. Rewind now plays five real trading days for seventeen of nineteen stories and bridges only the two yuan plots ([`33d9bc8`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/33d9bc8), [ADR 0073](docs/adr/0073-real-minutes-for-replay.md)). For Live, the agent tested the free sources from Fly's own machine and put four choices to me; I chose Yahoo Finance, Australian dollars and one position per pair ([`f5c76af`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/f5c76af), [ADR 0087](docs/adr/0087-marathon-on-real-prices-and-accounts-in-australian-dollars.md)). Live saves every five seconds, not every tick; when the agent found `CLAUDE.md` claiming "persist first", I had that window recorded as a choice, so a later agent would not read it as a bug.

## 4 Reviews I Did Not Accept Whole

I worked in Claude Code's auto mode and used other agents as reviewers: parallel subagents for reads, and Codex as an outside eye from a different model. Their findings can be confidently wrong, so I judged each against the running app. A Codex refactor gave the server an app factory and validated saves, but wrapped the saved files in a format the live version could not read, so a rollback would have crashed on start. I kept the files as they were, with the version beside them ([`37a0790`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/37a0790)).

## 5 Browsers Find What Tests Cannot

Green tests repeatedly hid a broken page, such as a tutorial pointer that left a blank one ([`5eb7dcf`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/5eb7dcf)), so `CLAUDE.md` requires a real-browser check after every deploy, with two sessions for anything multi-user. That rule caught the worst miss. I asked for gameplay ideas and chose all seven the agent proposed, including duels between two people over a round ([`804c6d5`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/804c6d5), [ADR 0095](docs/adr/0095-gameplay-for-the-player-and-the-room.md)). With every unit test green, a challenge never arrived in two live browsers: the page's action builder refused it, and the server's tests, posting directly, skipped that step. The fix added a browser check that clicks through a duel and an alert, and fails without the fix ([`e26b32c`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/e26b32c)); `CLAUDE.md` now says to trace a request across every boundary it crosses.

## 6 A Rename That Touched Saved Data

Once the tabs were Rewind, Random and Live, the code and saved files held three generations of old names, which an agent would misread. I chose to migrate the saved files rather than keep old names: Live's accounts moved once, with a backup, and tests hold it ([`b7def5f`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/b7def5f), [ADR 0091](docs/adr/0091-one-name-per-thing-in-the-code.md)).

## 7 An AI Agent at the Table

I wanted an AI agent to play beside people and asked the convenor first; he agreed, as an extra marked only if any MCP client could reach it from `/readme/`. I asked for every mode, then narrowed it to Live once the agent showed what rounds would cost: they count people by their open page, so an agent would need a new kind of presence, hours before freeze. The agent proposed answering the protocol by hand rather than adding the SDK on freeze day, and routing every tool through Live's own action, the one a page sends, so an agent could bend no rule a person cannot; I approved both ([`0a4a370`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/0a4a370), [ADR 0096](docs/adr/0096-an-ai-agent-plays-live-through-mcp.md)). Calling the server as an agent would found that an agent alone saw no price, since only a page started Live's polling; an agent's call now starts it, and Claude Code traded through it as a real client. A rule in `CLAUDE.md` and a check in `spec/` against the deployed app now hold both ([`f9fd592`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/f9fd592)).

## 8 Playing It with People

Family, friends and crit classmates played at once; some suggested features and layout. My mother, who invests in shares, found a full-account margin left her nothing for a second move, so a new order now starts at a quarter ([`e081fb6`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/e081fb6)). Bill McAlister, a tutor, suggested in a crit a holding fee for higher leverage. Real brokers charge none, but I applied it because it sharpens the warning: nothing at 1×, it eats the account at 1000× ([`ebe8d53`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/ebe8d53), [ADR 0058](docs/adr/0058-a-fee-that-grows-with-leverage-and-a-scale-for-every-rung.md)). The showcase will judge a larger room.

## 9 Deciding What Not to Build

Tutor Tom Griffiths' lecture offered prompts that make an agent a product partner, and on freeze day I tested the game as a product manager would. I had the agent write a PRFAQ, five likely players and forty candidates scored with RICE ([`2c9810a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/2c9810a), [review](docs/product.md)); the PRFAQ exposed that Live has one price source. RICE ranks small, safe changes first, so I judged each candidate against the README's idea instead. I built the top one that fit: ESMA's finding that most retail accounts lose now sits under the bell's leverage replay, where the laugh happens ([`3bb1853`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/3bb1853)). I rejected seven, three mid-table on RICE: a deposit bonus and paid luck break play money, and following a bot is the copy-trading brokers sell beginners. RICE never asks whether a feature betrays the idea, so that judgement stays mine.
