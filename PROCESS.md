# Process Overview

## 1 From the Brief to a Game

The brief asks for a multi-user, real-time website that is good, and leaves what "good" means to me. For crits 8 and 9 the app was Fridge Poetry, a shared door of word magnets where each word exists once ([ADR 0001](docs/adr/0001-plain-node-and-a-json-file.md) to [0008](docs/adr/0008-rounds-with-a-prompt.md)). It met every spec, but after crit 9 I judged it neither playable nor competitive. Scored rounds ([`4c5f328`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/4c5f328)) did not change that, nor did a letter race on a branch ([`c6fa7a1`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/c6fa7a1)): I don't find word games fun, and said multiplayer mattered more than the fridge.

I had it read classmates' work first: about 125 projects; co-op, arenas, racing and card games were crowded; nobody had built a market. I named strategy games and live markets, and twice stopped it combining them. Then I proposed a shared foreign-exchange market on real or simulated prices, where players compete by prediction and leverage, parodying *FX Fighter Kurumi-chan*. I asked for mainstream currencies, hidden-date replays of crises like 2008 and the 2015 franc unpegging, and a mode from today's price. I played the prototype, found it fun, chose to replace the fridge with it ([`66449d4`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/66449d4), [ADR 0009](docs/adr/0009-a-parody-fx-trading-floor.md)), and named it Losscut! Kurumi's FX Fantasy from the agent's suggestions.

## 2 Stack and Harness

The stack outlived the switch: Node, server-sent events, state on a Fly volume ([ADR 0001](docs/adr/0001-plain-node-and-a-json-file.md)). One process owns price, accounts and clock.

The harness has three parts. `README.md` argues what good means, and which claims are enforced or judged. Before choosing the game I had `CLAUDE.md` cut to rules alone ([`4269d0a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/4269d0a)), as facts belong in the README and brief; the switch added theme rules: play money, no official art, and satire of habits, not the people they hurt. `spec/` checks the running app; `test/` drives the rules tick by tick. Tests preceded `src/fx.ts` ([`8c98e74`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/8c98e74)).

## 4 Corrections

Browser checks found what tests could not. A 1000× bust left me idle three minutes, so the agent proposed borrowing from Dad: back in the game, never ahead, as debt comes off the result ([`2905ec8`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/2905ec8)). Finding repeated losscuts soft, I asked for a 0% cut; the agent advised against, and I chose that a losscut ends the round, a loan the only way back ([`84bbba4`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/84bbba4), [ADR 0026](docs/adr/0026-a-losscut-ends-your-round.md)). A player left with ¥27,676 could not borrow, as only zero could; the rule became "broke". The stream dropped as every tick resent all prices; ticks now carry only the new one.

Some fixes were to the agent's tests: a flaky room check compared names, which repeat, so it now compares codes ([`1ba83f9`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/1ba83f9)). After the switch I ran `/simplify`, and four reviews found where the prototype guessed what the server knew, such as inferring a stop-out from a balance drop. Both now come from the server ([`d654f9f`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/d654f9f)). `/code-review` then found a name cache growing per cookie, which I had fixed ([`f6d1e25`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/f6d1e25)).

## 6 Identity, Permission, Concurrency and the Log

A person is a cookie, shown by a name and code. I asked for chosen names with a draw button; the server judges each ([`f470ce8`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/f470ce8), [ADR 0017](docs/adr/0017-chosen-trader-names.md)). For anime names and more characters, the agent found three in later chapters; a browser check caught `app.js` failing past every test ([`5514e3c`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/5514e3c), [ADR 0018](docs/adr/0018-anime-names-and-seven-characters.md)). The server decides ([ADR 0010](docs/adr/0010-who-may-see-and-change-what.md)): a page sends only a choice, never a price; stops stay private. One process applies simultaneous actions whole: two Starts begin one round ([ADR 0014](docs/adr/0014-simultaneous-actions.md)). As crit 10 reads `flyctl logs`, I had bots removed ([`1f80392`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/1f80392)), and each action shares a request ID with its request line ([`e7a4c9d`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/e7a4c9d)).
