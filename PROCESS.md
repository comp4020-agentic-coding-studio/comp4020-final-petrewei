# Process Overview

The brief asks for a multi-user, real-time website that is good, and leaves "good" to me. I defined good as a room laughing at a wipe-out, then understanding why. This account is about how I directed agents toward that: the calls I made against the obvious alternative, how I knew each was right before accepting it, and what I threw away. The [decision records](docs/adr/README.md) hold the detail.

## 1 An Idea That Needs a Crowd

For crits 8 and 9 the app was Fridge Poetry, shared word magnets. After crit 9 I judged it unplayable; scoring rounds ([`4c5f328`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/4c5f328)) did not help, because nothing in it got better with more people. Rather than polish it, I had the agent survey what classmates were building, found co-op, racing and cards crowded, and proposed a shared FX market parodying *FX Fighter Kurumi-chan*, where leverage is both the joke and the lesson. I played the prototype before replacing the fridge ([`66449d4`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/66449d4), [ADR 0009](docs/adr/0009-a-parody-fx-trading-floor.md)). Shirky's situated software settled the scope: a game for one room, a crit group or the showcase, not a mass audience, so a wipe-out lands in front of people you know. I chose plain Node with JSON files over Astro or SQLite: one process owning the price suits a shared market, and a schema bought nothing for one small state. The cost, every rule a database would enforce written by hand, is why the harness comes next ([ADR 0001](docs/adr/0001-plain-node-and-a-json-file.md)).

## 2 A Harness That Says No

The danger in a trading game is a page that decides money, and an agent will write one if asked loosely. So I wrote rules into `CLAUDE.md` before the broker: the server owns every price and fill, and a page sends only what the player chose ([`4269d0a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/4269d0a), [ADR 0010](docs/adr/0010-who-may-see-and-change-what.md)), with tests written before `src/fx.ts` ([`8c98e74`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/8c98e74)). I knew the rule was working when it shaped a feature I had not foreseen: asked for an order at a typed price, the agent made the level a trigger the server fills at its own price, and a test holds it ([`30c59a4`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/30c59a4)). A rule that holds through a request inviting its breach is worth more than one that only describes the code.

## 3 Green Tests, Broken Page

Unit tests kept passing while the page was broken, so I stopped treating green as done. I chose all seven gameplay ideas the agent proposed, including duels ([`804c6d5`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/804c6d5), [ADR 0095](docs/adr/0095-gameplay-for-the-player-and-the-room.md)). Every test was green, yet in two real browsers a challenge never arrived: the page's request builder dropped it, and the server's tests, posting directly, skipped that step. Retrying would have hidden the gap. I fixed it at the harness: a browser check clicks through a duel and fails without the fix ([`e26b32c`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/e26b32c)), a unit check now lists every action the page sends, and `CLAUDE.md` says to trace a request across every boundary it crosses. The same class of bug has not returned.

## 4 Reviewers I Did Not Accept Whole

I used subagents for parallel reads and Codex as a reviewer from a different model, because one model reviewing its own work shares its blind spots. Their findings can be confidently wrong, so I judged each against the running app. A Codex refactor wrapped the saved files in a format the deployed version could not read, so a rollback would have crashed on start; I kept the format and took the rest ([`37a0790`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/37a0790)). On freeze day, a second Codex pass merged the two desks' pending orders into one function. Before accepting a change to money rules I asked how I would know it was equivalent: 534 tests passed, and a script fed 10,000 random orders to the old and new desks and found identical refusals and accounts ([`374d66c`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/374d66c)). A test review proposed removing fifteen checks; I removed only the two another named check still covered.

## 5 Real Prices, and Who Else Plays

Random ticks between daily closes invented everything finer, so I chose HistData's free minute bars: Rewind replays five real days around each crisis, dates hidden until the bell ([`33d9bc8`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/33d9bc8), [ADR 0073](docs/adr/0073-real-minutes-for-replay.md)). For Live, the agent tested free sources from Fly's own machine and put four choices to me; I chose Yahoo Finance and Australian dollars ([`f5c76af`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/f5c76af)). An empty room makes a newcomer give up, so I made the comic's seven characters real Live players, bankrupt and back like anyone, through the same action a page sends ([`207c75a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/207c75a)). I then let AI agents join over MCP after asking the convenor, narrowing my first request, every mode, to Live once the agent showed rounds would need a new kind of presence. Calling the server as a real client found that an agent alone saw no price; a rule in `CLAUDE.md` and a check against the deployed app now hold that agents bend no rule a person cannot ([`f9fd592`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/f9fd592), [ADR 0096](docs/adr/0096-an-ai-agent-plays-live-through-mcp.md)).

## 6 Playing It with People

Scripts cannot tell me whether a room laughs, so family, friends and crit classmates played at once. My mother, who invests in shares, found a full-account margin left her nothing to decide, so a new order now starts at a quarter ([`e081fb6`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/e081fb6)). Bill McAlister, a tutor, suggested in a crit a holding fee that grows with leverage. Real brokers charge none, but I applied it because it sharpens the lesson: nothing at 1×, ruinous at 1000× ([`ebe8d53`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/ebe8d53)). I took the first because it matched how a real investor plays, and the second despite its unrealism because it served the idea.

## 7 Deciding What Not to Build

On freeze day I used Tom Griffiths' product prompts to test the game as a product manager would: a PRFAQ, five likely players and forty candidates scored with RICE ([`2c9810a`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/2c9810a), [review](docs/product.md)). The PRFAQ exposed a real risk, one price source for Live. RICE ranks small, safe changes first, so I judged each candidate against the idea instead. I built ESMA's finding that most retail accounts lose beneath the bell's leverage replay, where the laugh happens ([`3bb1853`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/3bb1853)), and a QR code so a showcase crowd joins from phones ([`831600f`](https://github.com/comp4020-agentic-coding-studio/comp4020-final-petrewei/commit/831600f)). I rejected seven; a deposit bonus and paid luck scored mid-table but break play money. Checking the list against the app before building showed four top candidates already existed: the agent had ranked from documents, not the running game. RICE never asks whether a feature betrays the idea, or whether it is already there; both judgements stayed mine.
